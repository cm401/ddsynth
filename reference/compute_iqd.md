# Compute Integrated Quadratic Distance (IQD)

Compute Integrated Quadratic Distance (IQD)

## Usage

``` r
compute_iqd(fit, true_params, dist_type, x_grid = NULL)
```

## Arguments

- fit:

  Stan fit object

- true_params:

  List of true parameters

- dist_type:

  Distribution type

- x_grid:

  Grid of x values for integration

## Value

IQD value
